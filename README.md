# CH 102 Lab Final Prep

A visual, guided study site for the NC State CH 102 lab final: all 11 labs plus lab skills, an interactive diagram for every lab, formulas, calculation drills, a 134-question quiz, a 30-question mock exam, flashcards, and a printable exam sheet.

## Put it online with GitHub Pages (about 3 minutes)

1. Sign in at github.com and click **New repository** (the **+** at the top right → New repository).
2. Name it something like `ch102-final`, set it to **Public**, and click **Create repository**.
3. On the new repo page, click **uploading an existing file**.
4. Drag in all of these files at once (keep them together, no folder needed):
   `index.html`, `style.css`, `data.js`, `visuals.js`, `app.js`, `exam-sheet.pdf`, `README.md`
5. Click **Commit changes**.
6. Go to **Settings → Pages**. Under **Build and deployment**, set **Source** to *Deploy from a branch*, pick the **main** branch and the **/ (root)** folder, and click **Save**.
7. Wait a minute or two, then refresh that page. Your link appears at the top: `https://YOUR-USERNAME.github.io/ch102-final/`.

To use it without GitHub, double-click `index.html`; it runs in any browser.

## What's inside

| File | What it does |
|---|---|
| `index.html` | The page and its sections |
| `style.css` | All the styling (light and dark mode) |
| `data.js` | Lab notes, quiz questions, flashcards |
| `visuals.js` | The interactive diagrams |
| `app.js` | Navigation, quiz, drills, mock exam, flashcards |
| `exam-sheet.pdf` | Two-sided letter sheet to print for the exam |

Progress (quiz answers, known flashcards, checklist) is saved in your own browser only.

Content comes from the CH 102 Lab eManual and from your own prelab/postlab work. Where your lab results differed, trust your own data.
